# FORMULA OIL — сайт сервісу заміни оливи

Багатосторінковий преміальний сайт на чистому HTML / CSS / JS з GSAP-анімаціями.
Тёмна техно-преміум тема, індивідуальний дизайн, прелоадер із логотипом та плавні переходи між сторінками.

## Структура
```
index.html        — Головна
services.html     — Послуги + прайс + FAQ
about.html        — Про нас + команда
contacts.html     — Контакти + форма запису (чипси) + мапа
assets/
  css/style.css   — дизайн-система (токени, компоненти, адаптив)
  js/app.js       — прелоадер, переходи, reveal (IntersectionObserver, 1 раз),
                    кастом-курсор, магнітні кнопки, паралакс, лічильники, FAQ, чипси
  js/vendor/      — GSAP + ScrollTrigger + ScrollToPlugin + lax.js (локально)
  img/            — фото (Pexels) + обличчя для відгуків (thispersondoesnotexist)
_libs/serve.mjs   — простий локальний статичний сервер для розробки
```

## Запуск локально
```bash
node _libs/serve.mjs      # http://localhost:5678
```
Або будь-який статичний сервер із кореня проєкту.

## Особливості
- **Прелоадер** із логотипом і лічильником; між сторінками — плавний перехід-шторка.
- **Анимації появи** — через IntersectionObserver з `unobserve`, тому кожен блок з’являється **рівно один раз**.
- **Фішки**: кастомний курсор, магнітні кнопки, біжучий рядок, паралакс зображень,
  clip-mask reveal заголовків, акордеон FAQ, чипси вибору послуги, лічильники.
- **Адаптив**: edge-to-edge шапка + топбар, широкий контейнер, full-bleed секції.
- `prefers-reduced-motion` — анімації вимикаються.

## Треба замінити перед продакшеном
- **Логотип** — зараз тимчасова крапля оливи (SVG у кожній сторінці, `#oilgrad`). Заміните на фінальний.
- **Фото** з Pexels — безкоштовні; за потреби додайте атрибуцію або власні знімки.
- **Обличчя у відгуках** — згенеровані (thispersondoesnotexist), не реальні люди. Заміните на реальні фото клієнтів/аватари.
- **Форма** — зараз демо (без бекенду). Підключіть відправку (email / Telegram / CRM).
- **Мапа** — Google Maps embed за адресою; уточніть точну точку.
- Шрифти підключені з Google Fonts (Unbounded, Manrope, JetBrains Mono) — за бажанням саміть self-host.
